Virtual Hand Mouse Controller
📌 Overview

A real-time virtual mouse controlled using hand gestures. This project uses OpenCV, Autopy, and a custom Hand Tracking Module to move the cursor and perform clicks without touching a physical mouse.

🚀 Features

Real-time hand detection

Move mouse using index finger

Click using pinch gesture (index + middle finger)

Smooth cursor movement

FPS display

🛠️ Technologies Used

Python

OpenCV

Autopy

NumPy

📂 Project Structure

virtual-hand-mouse/
│── main.py

⚙️ Installation

Install the required Python packages: opencv-python, numpy, autopy.

▶️ Run

Run the main application file: main.py
